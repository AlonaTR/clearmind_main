# ClearMind

ClearMind is a web application designed to guide you through meditation and mindfulness practices.  
Its simple, intuitive interface helps you relax, refocus, and find a moment of calm during your busy day.

## Features
- **Guided Meditation Sessions:** Access a variety of meditation techniques to suit your mood.
- **Modern Interface:** Built with React for a responsive and engaging user experience.
- **Robust Backend:** Powered by Python and managed with Docker for seamless deployment.
- **Scalable Architecture:** Utilizes Docker Compose and an Nginx backend server to ensure smooth performance.
